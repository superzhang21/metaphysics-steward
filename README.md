## 重新定义排盘

你有没有试过在网上排八字？

打开一个网页，填上出生时间，点"排盘"——然后满屏广告。关掉广告，看到结果——然后发现排错了。换个网站，再排一次——结果又不一样。

**为什么同一个八字，不同工具排出来不一样？**

因为有的用真太阳时，有的不用；有的节气换柱精确到分钟，有的精确到天；有的晚子时换日，有的不换。

每一个细节的差异，都可能导致时柱甚至日柱完全不同。

**我们需要的不是一个"能排盘"的工具，而是一个"排得对"的工具。**

这就是玄学管家的起点。

## 它是一个 Skill

玄学管家的核心身份是 **AI Agent Skill**。

`SKILL.md` 放在仓库根目录，包含完整的元数据——名称、描述、标签、能力清单、使用方法、参数说明。任何支持 Skill 协议的 AI Agent（Hermes Agent、Claude Code、Codex CLI 等）打开这个仓库后，**自动识别、自动安装、直接调用**。

```
用户: "帮我排一个 1990 年立春后出生的男命八字"
Agent: [自动调用 scripts/steward.py --mode bazi ...]
Agent: "四柱：庚午 戊寅 庚子 辛巳。日主庚金，坐子水伤官……"
```

**不需要手动配置。不需要记命令。不需要看文档。**

说人话就行。

它也是一个 CLI 工具——`pip install` 然后 `python3` 就跑。但 Skill 才是它的完全体。

## 实战案例

### 案例一：对话式排盘

> 用户对 Agent 说：

**用户：** 帮我排一个 1988 年农历九月初九上午十点出生的男命八字

**Agent：** 好的，正在排盘。

```
分析基准: 1988-10-08 10:18:33 (真太阳时)
输入时间: 1988-10-08 10:00 (民用时)

【四柱】戊辰  壬戌  丙寅  癸巳
【十神】食神  七杀  日主  正财
【大运】6岁起运 → 癸亥 → 甲子 → 乙丑 → 丙寅 → 丁卯 → 戊辰 → 己巳
```

**用户：** 日主丙火生于戌月，身强还是身弱？

**Agent：** 丙火坐寅木长生之地，寅中甲木偏印生身，巳中丙火有根。但月干壬水七杀透出克身，时干癸水正财耗泄。综合——**身弱偏中和**，喜木火帮身。

> 真太阳时 10:18:33 vs 输入 10:00，差 18 分钟。这 18 分钟决定了时柱是癸巳还是甲午。

### 案例二：合婚分析

**用户：** 我 1990 年 2 月 4 号上午十点半出生，对象 1991 年元旦中午出生，帮我们合个婚

**Agent：**

```
【合婚评分】82 分 🟢

男命: 庚午 戊寅 庚子 辛巳 (属马)
女命: 庚午 戊子 甲子 庚午 (属马)

✓ 生肖: 同属马，不冲不害
✓ 日干: 庚甲——刚柔相济
✓ 纳音: 路旁土 配 路旁土——同类相扶
✓ 日支: 子子——比和，夫妻宫和谐
⚠ 大运: 部分重叠
```

**用户：** 82 分算什么水平？

**Agent：** 80 分以上中上，90 分以上天作之合。你俩属于**互相看得顺眼、日子能过好**的组合。日支比和说明夫妻宫稳定，庚甲相合说明性格互补。唯一的大运重叠意味着人生节奏同步——好处是一起起伏，坏处是没法互补兜底。总的来说，**这婚可以结。**

### 案例三：梅花起卦

**用户：** 我刚看了眼时间 15:37，帮我用梅花起一卦

**Agent：**

```
本卦: 火泽睽 | 互卦: 水火既济 | 变卦: 火雷噬嗑
动爻: 第 2 爻 | 体: 离(火) | 用: 兑(泽)
体用关系: 体克用——我强敌弱
```

**用户：** 什么意思？

**Agent：** 睽卦，火在泽上，方向相反，代表**分歧或误解**。但体卦离火克用卦兑金，你占主动。变卦噬嗑，口中有物，需要**沟通才能解决**。互卦既济，最终结果是好的。简单说：**现在有点拧巴，但你能搞定，别急。**

## 参数速查

| 参数 | 说明 | 示例 |
|---|---|---|
| `--birthdate` | `YYYY-MM-DD HH:MM` | `"1990-02-04 10:40"` |
| `--sex` | 1 男 / 0 女 | `1` |

| `--male` / `--female` | 合婚出生时间 | `"1990-02-04 10:40"` |
| `--no-true-solar` | 关闭真太阳时 | 标志位 |

## 技术亮点

**真太阳时** — 经度 + 均时差方程双重修正，精确到秒。北京和乌鲁木齐差 2 小时，同一个八字排出来时柱可能不一样。

**节气换柱** — 按节气换，不按农历。立春换年，换节换月，精确到交节时刻。

**六爻装卦** — 京房八宫纳甲体系，64 卦 384 爻，每爻有纳甲、六亲、六神。
