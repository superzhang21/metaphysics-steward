# 八字合婚要则（Hehun · 完整版）

`scripts/core/hehun.py` 实现完整版合婚分析（双造同排 + 用神互补 + 神煞警示 + 大运同频），供婚配参考。

## 合婚维度与权重

| 维度 | 内容 | 权重影响 |
|---|---|---|
| 生肖（年支） | 六合 / 三合 / 六冲 / 六害 / 相刑 | -3 ~ +10 |
| 年命纳音 | 五行相生 / 相克 / 同气 | -4 ~ +5 |
| 日干 | 天干五合（甲己/乙庚/丙辛/丁壬/戊癸）/ 五行生克 | -4 ~ +10 |
| 夫妻宫（日支） | 六合 / 三合 / 六冲 / 六害 / 相刑 | -8 ~ +10 |
| 五行互补 | 一方命局缺失五行、另一方该行较旺即补 | 0 ~ +6 |
| 喜用神互补 | 依日主强弱（同党占比 ≥62% 身强 / ≤38% 身弱 / 其余中和）断用神；对方命局补我方用神则加 | -2 ~ +8 |
| 神煞警示 | 阴差阳错日 / 魁罡日 / 孤辰寡宿 / 桃花 / 红鸾天喜 等 | -7 ~ +1 |
| 大运同频 | 双方十年大运按公历年份对齐，评估"喜用吉运"重叠（起运后 50 年窗口） | 0 ~ +6 |

基线 60 分，叠加后截断至 [0,100]。
评级：≥85 上等；70-84 中上；55-69 中等；<55 普通（需谨慎经营）。

## 喜用神断法（简化·可解释）

- 统计五行强度：四柱天干、地支、藏干主气各记 1 / 1 / 0.5。
- 同党 = 日主五行 + 印（生我）；异党 = 食伤（我生）+ 官杀（克我）+ 财（我克）。
- 身强 → 用神在官杀/食伤/财中取命局最弱者；身弱 → 用神在印/比劫中取最弱者；
  中和 → 取全局最缺之五行调候。
- 用神互补：一方命局中对方用神五行 ≥2.0 记"能补"（+4/侧，双方互补 +8）。

## 婚姻相关神煞速查

- 桃花（咸池）：申子辰见酉、寅午戌见卯、巳酉丑见午、亥卯未见子（以年支局取）。
- 华盖：申子辰见辰、寅午戌见戌、巳酉丑见丑、亥卯未见未。
- 驿马：申子辰见寅、寅午戌见申、巳酉丑见亥、亥卯未见巳。
- 孤辰 / 寡宿：亥子丑 → 寅/戌；寅卯辰 → 巳/丑；巳午未 → 申/辰；申酉戌 → 亥/未。
- 羊刃（阳干）：甲卯、丙午、戊午、庚酉、壬子。
- 魁罡日：庚辰 / 庚戌 / 壬辰 / 戊戌。
- 阴差阳错日：丙子 / 丙午 / 丁丑 / 丁未 / 戊寅 / 戊申 / 辛卯 / 辛酉 / 壬辰 / 壬戌 / 癸巳 / 癸亥。
- 红鸾 / 天喜：年支起（子年在卯逆行），天喜居红鸾对宫。

## 输出结构（JSON）

`analyze()` 返回：
- `male` / `female`：`gz`（四柱）、`day_master`、`day_master_wx`、`nayin_year`、`shengxiao`，
  另含 `pillars`（每柱 gz/gan/zhi/shishen/nayin/hidden 藏干明细）、
  `yun`（起运 start_desc/start_time + 大运 da_yun[]）、
  `yongshen`（element/reason）、`shensha[]`。
- `items`：逐条分析文本；`score`：百分制；`verdict`：评级；`render`：终端文本。

## 使用

```bash
python3 steward.py --mode hehun \
  --male "1990-02-04 10:40" --female "1991-01-01 12:00" --birthplace 116.4
# 双方不同出生地（真太阳时分别校正）
python3 steward.py --mode hehun \
  --male "1990-02-04 10:40" --male-lon 116.4 \
  --female "1991-01-01 12:00" --female-lon 108.9
# JSON 输出（all/json 模式下同时给 --male/--female 即含合婚）
python3 steward.py --mode json --male "..." --female "..."
```

## 局限

- 用神断法为五行平衡简化口径，未含调候/格局/从格等进阶；婚配吉凶须结合双方完整命局、大运流年综合判断。
- 大运同频仅按公历年份对齐比较"喜用吉运"重叠，未细化流年。
- 本模块仅供传统文化参考，不构成婚恋决策建议。
